# python-penjualan-buah

# Toko Buah dengan Python
Program sederhana untuk menampilkan daftar buah, melihat harga, melakukan pembelian, dan menghitung diskon.

## Preview Program

Program memiliki beberapa proses:
- Menampilkan daftar buah.
- Menampilkan harga buah.
- Memilih buah yang ingin dibeli.
- Memasukkan jumlah pembelian.
- Menghitung total harga dan diskon.
- Menampilkan hasil pembayaran.

## Data Buah

| Nama Buah | Harga |
|---|---:|
| Mangga | Rp7.500 |
| Apel | Rp10.000 |
| Jeruk | Rp8.000 |
| Melon | Rp21.000 |
| Alpukat | Rp11.500 |
| Nanas | Rp17.000 |

## Diskon

| Total Belanja | Diskon |
|---|---:|
| > Rp150.000 | 10% |
| > Rp100.000 | 5% |
| > Rp75.000 | 3% |
| ≤ Rp75.000 | 0% |
